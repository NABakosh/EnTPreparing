# Решения по умолчанию

- Next.js 16: вместо `middleware.ts` используется `src/proxy.ts` (middleware переименован в proxy). Он только проверяет JWT и роль по префиксу пути; полная проверка прав — в каждом сервисе/обработчике.
- Prisma зафиксирована на 6.x (стабильный API без driver adapters); переход на 7.x — отдельной задачей.
- shadcn/ui инициализирован в стиле `base-nova` (примитивы Base UI, а не Radix): вместо `asChild` используется `render` или `buttonVariants()` на `<Link>`.
- i18n без префикса языка в URL: язык хранится в cookie `NEXT_LOCALE` (по умолчанию `kk`).
- Казахские строки интерфейса написаны разработчиком без проверки носителем языка; желательно вычитать перед показом.
- Локальный Postgres в docker-compose слушает порт 5433 (5432 часто занят системным Postgres).
- JWT в httpOnly cookie `session`, срок 7 дней, алгоритм HS256, секрет `JWT_SECRET`. Заблокированный пользователь отсекается при каждом запросе к БД через `requireUser()`.
- Логин: транслит ФИО латиницей «фамилия.и» (например `ivanov.a`), при совпадении добавляется число.
- Пароль: 8 символов из алфавита без похожих символов (без O/0/l/1/I), криптостойкий генератор.
- Учитель может вести несколько классов (связь многие-ко-многим); «свой класс» = любой из его классов.
- Программа ученика = 3 обязательных предмета (история Казахстана, мат. грамотность, грамотность чтения) + 2 предмета выбранной профильной пары. Профиль выбирается учеником на дашборде / при старте пробного экзамена.
- Сертификат: все темы всех модулей программы пройдены с результатом ≥ порога (`module_threshold`, по умолчанию 60%).
- Схема баллов (`src/config/scoring.ts`): одиночный выбор — 1 балл; множественный — 2 балла за полностью верный, 1 балл при одной ошибке, иначе 0. Профильный раздел: 30 заданий с одним ответом + 10 с несколькими = 50 баллов. **Нужно сверить с официальной спецификацией Национального центра тестирования (НЦТ).**
- Если в банке не хватает опубликованных вопросов для раздела, пробный экзамен берёт сколько есть, а максимум баллов пересчитывается (видно в результатах).
- FAQ, ссылки соцсетей, контакты, дата ҰБТ и порог модуля хранятся в таблице `Setting` (JSON), редактируются админом.
- Новости: текст хранится как HTML из Tiptap и очищается `sanitize-html` перед выводом. Обложка — URL (загрузка файлов на Vercel без внешнего хранилища невозможна; см. KNOWN-ISSUES).
- Rate limit ИИ-ментора считается по таблице `MentorLog` (30 запросов в час на пользователя), чтобы работать на serverless без Redis.
- Поиск по книгам v1: PostgreSQL FTS. Колонка `tsv` заполняется триггером (`to_tsvector('russian', chapter || text)`), GIN-индекс; запрос `to_tsquery('russian', 'слово1:* | слово2:* …')` — значимые слова через OR с префиксным поиском (помогает казахским словоформам, т. к. казахского стеммера нет), ранжирование `ts_rank_cd`. Фильтры: класс ≤ класса ученика, предмет по `src/config/book-subjects.ts`; при пустом результате фильтр предмета снимается.
- Если фрагменты не найдены, ментор отвечает «в учебниках не найдено» без вызова модели (экономия лимитов, нет галлюцинаций). Источники в интерфейсе показываются из найденных фрагментов, а не со слов модели.
- Cerebras: базовый URL `https://api.cerebras.ai/v1`, модель `gpt-oss-120b` (сверено с документацией Cerebras Inference, ноябрь 2026). Провайдеры вызываются через fetch к OpenAI-совместимому `/chat/completions`, без SDK.
- Демо-активность учеников (тесты и пробные экзамены за последние 3–4 недели) создаётся в seed, чтобы графики и статистика учителя/родителя были заполнены. Отключается `SEED_ACTIVITY=0`.
- Деплой: скрипт `vercel-build` выполняет `prisma migrate deploy` перед сборкой.
- pgvector в будущем: `CREATE EXTENSION vector; ALTER TABLE "BookChunk" ADD COLUMN embedding vector(1024);` + HNSW-индекс; при ingest считать эмбеддинги, в `searchChunks` объединять FTS и векторный поиск (reciprocal rank fusion).
- `cacheComponents` (включён шаблоном create-next-app) выключен: страницы динамические (`force-dynamic`), данные зависят от cookie/сессии; так проще и предсказуемее для демо.
- Проверку вопросов (очередь DRAFT/REVIEW) может выполнять любой учитель по всем предметам — предметной привязки учителей к банку вопросов пока нет. Учитель не может менять уже опубликованные вопросы; это делает только админ.
- Импортированные из Excel/CSV вопросы всегда получают статус DRAFT и публикуются только после проверки (так же, как вопросы, созданные ИИ). Казахский флаг `needsReviewKk` ставится автоматически, если в строке нет казахского текста или вариантов.
- Смена или сброс пароля увеличивает `User.sessionVersion` — все ранее выданные JWT становятся недействительными. Выход из аккаунта удаляет cookie только на текущем устройстве.
- Учебники: OCR-тексты Мектеп 2018–2019 (8–11 классы, русский язык) из `~/Documents/bookcatalog/texts`, ~14,2 тыс. чанков. Метаданные берутся из YAML-заголовка файла, книга подписывается «Предмет, автор, N класс, часть K (год)». Английский язык тоже загружен (`--skip none`), хотя предмета на платформе пока нет — пригодится для профиля «иностранный язык». Учебники физики (8–11, 3,5 тыс. фрагментов) загружены позже; конспекты физики «без учебника» переписаны по ним (`--refresh-nobook`).
- Генерация вопросов ищет фрагменты без ограничения по классу темы (учебники начинаются с 8 класса), варианты перемешиваются перед сохранением (модель часто ставит верный первым). При 429 от Cerebras — ожидание 15/30/45 с, между темами пауза `--delay` (3 с).
- Цвета взяты из прошлой версии проекта (github.com/NABakosh/EnTPreparing): акцент синий #2563eb, фон slate #f8fafc, текст #0f172a, рамки #e2e8f0, hero с градиентом от blue-50, карточки с подсветкой рамки и тенью при наведении. Вторичный текст — slate-600 (#475569) вместо slate-500 ради контраста 4.5:1.
- Название сайта статичное, одно на обоих языках: «ENT Preparing» (`BRAND` в `src/config/site.ts`). Логотип — текстовый значок «ENT»; картинку можно подключить через `SITE_LOGO` (файл в `public/`).
- Достройка программы (`npm run build-curriculum`): модель предлагает недостающие темы по спецификации ҰБТ, конспект пишется по фрагментам учебников (RAG); если учебников по предмету нет (грамотность чтения, математическая грамотность) — по школьной программе с пометкой «ИИ-конспект, без учебника». Такие темы видны ученикам сразу (с плашкой «составлено ИИ, проверяется учителями»), а вопросы к ним — только после публикации учителем.
- Добавлены предметы «Биология» и «Химия» и профильная пара «Биология — Химия» (учебники по ним есть).
- Профильным предметам генерируются и задания с несколькими верными ответами (`--multi 2` на тему), чтобы набрать 10 таких заданий для пробного экзамена.
- «История Казахстана» — структура задана вручную по спецификации ҰБТ (`scripts/curate-history.ts`, 8 модулей, 35 тем в хронологическом порядке); ИИ пишет только конспекты и вопросы. Предложенная моделью структура истории была неполной и содержала второстепенные темы.
- Сертификат оформлен по образцу школы (A4, книжный). Фон — `src/server/assets/certificate-bg.pdf`, подписант — `CERTIFICATE_SIGNER` в `src/config/site.ts`. Скан печати и подписи не вшивается (сертификат выдаётся автоматически): место оставлено для живой подписи и печати. Образец со сканом в .gitignore.
