# Известные недоработки

- Казахские строки интерфейса и демо-контента не вычитаны носителем языка.
- Демо-вопросы (seed) помечены «ДЕМО» и не являются проверенными заданиями ҰБТ. Схему баллов нужно сверить со спецификацией НЦТ (`src/config/scoring.ts`).
- Учебники — OCR сканов: формулы (алгебра, геометрия, химия) распознаны плохо, встречаются опечатки распознавания. Для истории и биологии качество хорошее.
- Учебники английского загружены, но предмета «Английский язык» на платформе пока нет.
- 60 вопросов, сгенерированных ИИ (история, информатика), ждут проверки учителем в «Проверке вопросов»; в них возможны неточности.
- Перевод на казахский (`scripts/translate-kk.ts`) на реальном API ещё не запускался.
- Обложка новости задаётся только URL: загрузка файлов требует внешнего хранилища (например, Vercel Blob) — не подключено.
- Защита от перебора паролей хранится в памяти процесса: на serverless (несколько инстансов) она слабее. Для продакшна — лимит на уровне БД/Redis или Vercel Firewall.
- Отметки «вернуться к вопросу» в пробном экзамене хранятся в localStorage браузера (не переносятся между устройствами); ответы сохраняются на сервере.
- Учитель видит очередь проверки вопросов по всем предметам (нет привязки учителя к предмету банка вопросов).
- Нет восстановления пароля по e-mail/SMS — пароль сбрасывает учитель или администратор.
- После изменения `messages/*.json` нужно перезапускать dev-сервер.
- PDF-сертификат использует шрифты DejaVu Sans и Liberation Serif Bold (встроены в репозиторий, свободные лицензии). Логотип вырезан из скана образца — при наличии исходника лучше заменить.
- Учитель может сбросить пароль родителю, у которого хотя бы один ребёнок в его классе (родитель видит всех своих детей).
- Ответы ИИ-ментора на вопросы из истории диалога, присланной клиентом, не проверяются отдельно (модель всё равно опирается только на фрагменты учебников).
- Лимиты Cerebras на текущем ключе: 5 запросов/мин, 30 тыс. токенов/мин, 1 млн токенов/сутки. Генерация контента и ИИ-ментор на сайте делят один лимит: пока идёт массовая генерация, ментор может отвечать «перегружен». Решение — платный тариф Cerebras или отдельный ключ для генерации.
- Продакшн-база заполняется копией локальной (`scripts/sync-to-prod.sh`) — после запуска для реальных учеников так делать нельзя (затрёт их данные); контент тогда переносить выборочно.
